# Python para Redes

## Programación y automatización con SNMP, SSH, APIs y más desde cero

Repositorio oficial del libro **Python para Redes**.

Este repositorio contiene ejemplos, ejercicios, proyectos y librerías desarrolladas a lo largo del libro.

---

## 📘 Sobre el libro

Este libro fue diseñado para profesionales de redes, monitoreo, operación y automatización que desean aprender Python de forma práctica y aplicada desde cero.

A lo largo del libro aprenderás:

* Fundamentos de Python
* Expresiones regulares (regex)
* Manejo de errores
* Programación orientada a objetos
* Manejo de archivos
* SSH y SFTP
* SNMP
* APIs
* Concurrencia
* Logging
* Automatización de redes

El enfoque principal del libro es resolver problemas reales de automatización y operación de redes utilizando Python.
